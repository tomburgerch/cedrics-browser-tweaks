# YouTube Speed Saver

A Chrome extension that remembers your preferred YouTube playback speed and applies it automatically to every video.

## Features

- Automatically sets your preferred playback speed on every YouTube video
- Persists across page navigations, new tabs, and browser restarts
- Syncs your preference across devices via Chrome sync
- Simple popup UI to change speed (1x, 1.25x, 1.5x, 1.75x, 2x, 2.5x)
- Default speed: 2x

## Installation

1. Clone this repo
2. Open `chrome://extensions/` in Chrome
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select the project folder
5. Open any YouTube video — your preferred speed is applied automatically

## Usage

Click the extension icon in the toolbar to change your preferred speed. The selected speed is saved instantly and applied to all YouTube videos.
